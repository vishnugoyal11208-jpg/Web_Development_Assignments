Product Overview

The NovaBook Pro X1 is a modern performance laptop designed for students, professionals, programmers and creative users. It combines a powerful processor, fast storage and a high-quality display in a lightweight design.

Technical Information

RAM
RAM stands for Random Access Memory. It temporarily stores data that the computer is currently using.
SSD
SSD stands for Solid State Drive. It is used for storing the operating system, applications and personal files.
Refresh Rate
Refresh rate is the number of times the display refreshes the image every second. It is measured in Hz.
Warranty
A warranty is a period during which the manufacturer provides support for eligible product defects according to its warranty terms.

Display size can be measured in inches, while storage capacity is commonly measured in GB or TB.

Storage example: 1 TB = approximately 1024 GB.
